# Mumutte / ミュミュット

macOSのメニューバーに常駐し、選択した入力デバイスの入力ゲインを定期的に0%へ戻す小さなユーティリティです。マイク音声そのものは取得しません。

## できること

- 監視する入力デバイスを1つ選択
- 監視開始時にすぐ確認し、その後10分ごとに入力ゲインを確認
- 最終確認時刻を保存して表示し、監視中は次回確認時刻も表示
- 入力ゲインが上がっていたら0%に設定
- 設定に成功したとき、macOSの通知を表示
- メニューバー内に、ゲインを下げた時刻とデバイス名を直近10件まで表示
- 選択したデバイスと監視状態を保存し、次回起動時に復元
- macOSへのログイン時に起動する設定

## 動作環境

- macOS 13以降
- ビルドにはSwift 6以降のツールチェーン（XcodeまたはCommand Line Tools）が必要
- 外部のSwiftパッケージへの依存はありません

## ビルドと起動

プロジェクトのルートディレクトリで実行します。

~~~sh
./build-app.sh
open .build/Mumutte.app
~~~

アプリはメニューバーに表示されます。通常のアプリケーションウインドウやDockアイコンは表示しません。

ビルド時にバージョンとコミットの短いSHAをアプリへ埋め込みます。`v0.1.0` タグからビルドするとバージョンは `0.1.0` になり、コミットSHAも記録されます。メニュー下部ではSemVerのビルドメタデータ表記 `v0.1.0+<sha>` で表示し、Gitコミットがない場合は `v0.1.0+none` になります。ローカルでは `APP_VERSION=0.1.0 ./build-app.sh` のようにバージョンを指定でき、指定がない場合は最新タグ、タグがなければ `0.1.0` を使います。

## GitHub Actionsのリリース

`v*`形式のタグをpushしたときだけ、Apple Silicon（arm64）とIntel（x86_64）向けにビルドし、GitHub ReleaseへZIPを添付します。例:

~~~sh
git tag v0.1.0
git push origin v0.1.0
~~~

自動ビルドではアプリバンドルにad-hoc署名を付けて整合性を検証します。Developer ID署名とApple Notarizationは行いません。初回起動時に警告が出た場合は、FinderでアプリをControl-clickして「開く」を選ぶか、システム設定の「プライバシーとセキュリティ」から「このまま開く」を選んでください。Mumutteはメニューバーに表示され、Dockには表示されません。Developer ID署名・Notarizationには別途証明書と公証設定が必要です。

## 使い方

1. メニューバーのマイクアイコンをクリックします。
2. 「対象の入力デバイス」から監視したいデバイスを選びます。
3. 「監視を開始」を押します。開始直後に1回確認し、以降は10分ごとに確認します。
4. 通知が必要な場合は、最初に表示されるmacOSの通知許可を有効にします。
5. Macへのログイン後に自動で起動したい場合は、「ログイン時に起動」を有効にします。

監視中は設定したデバイスの選択を変更できません。監視を止めてから対象を選び直してください。アプリを終了しても監視状態は保存され、次回起動時に監視を再開します。

## 動作のしくみ

Mumutte（ミュミュット）はCore Audioから入力デバイスのゲイン設定値を読み取り、上がっている場合に0を設定します。設定に成功した場合だけ履歴を保存し、通知を送ります。通知を許可しない場合でも、履歴はアプリ内に残ります。

## 制約と注意点

- 監視対象は選択した1台です。システム全体やアプリごとのマイク設定は変更しません。
- 入力ゲインを読み取れない、または変更できないデバイスは監視できません。対象一覧では「操作不可」と表示されます。
- 0%はデバイスの入力ゲインを最小値にする設定です。機器やドライバによっては、ハードウェア上の完全なミュートと同じ動作にならないことがあります。
- 入力ゲインの値だけを読み書きします。マイク音声の録音・解析はせず、マイク録音の権限も要求しません。
- アプリが起動している間に監視します。Macがスリープ中は確認できず、復帰後に確認します。
- ゲインが上がってから次の確認までは最大10分かかります。すぐにミュートする必要がある場面では、会議アプリやマイク本体のミュートも併用してください。
- デバイス一覧は起動時と監視中に更新します。監視していない間に接続した機器が一覧に出ない場合は、アプリを再起動してください。
- 「ログイン時に起動」はmacOSのログイン項目を使います。登録後にシステム設定で許可が必要な場合があります。ローカルビルドではコード署名の状態によって自動起動が許可されないことがあります。
